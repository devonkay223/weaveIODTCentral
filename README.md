# Form to Fiber: Weaving Interoperable Data File Format

The JSON weaving data format was created to provide data centralization, interoperability, and extensibility to data created and moved between a series of tools for designing zero waste form woven garments. 

This site, and all the resources associated with our JSON file format is [open source](https://github.com/obsidianmd/jsoncanvas) under the MIT license.
