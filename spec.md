# JSON Form to Fiber Spec

<small>Version 1.0 2026-09-01</small>

## Top Level 
 The top level contains these data types: 
 - `Loom` (required, one instance, loom specs)
 - `ArtWork Areas` (optional, multiple entries, svg artwork zone)
 - `Form Pieces` (optional, multiple entries, geometric 3D pattern definition - based on Clo patterning)
 - `Weave Structure` (optional, multiple entries, single repeat weave structure def)
 - `Yarn` (optional, multiple entries, yarn data)


## Loom  
- `TotalWarpEnds` (required, int) is the number of warp ends.  
- `TotalDesignHooks` (optional, int) is the number of warp ends per repeat.
- `WeftSelectors` (optional, int) is the number of weft yarns available. 
- `EndsPerCm` (optional, int) is the number of warp ends per cm.  
- `NumberOfRepeats` (optional, int) is the number of pattern repeats on loom. 
- `TypesOfRepeat` (optional, mirrored/reg) is the repeat type for the loom. 
- `Mappings`
  - `Fiber` (optional, array of Fiber ref) array containing fiber id and ends distribution (start, end)


## FormPieces
- `Name` (required, unique string) name formatted as P(piece number).(layer number) (ex: P3.2 is the third piece layer 2)
  - `ID` (optional, unique string) ID value generated by Clo
  - `LayerSystem` (optional, unique string) inherits from name in canonical clay workflow.
  - `Geometry` (optional, list) geometry description of pattern pieces from Clo
    - `Index` (required, list entry id)
      - `ID` (required, string) line ID from Clo.
      - `PointList` (require, list) list of points from Clo.
        - `ID` (required, string) point ID from Clo
        - `PointType` (require, string - Straight/ Bezier Curve) 
        - `Position` (required, dict)
          - `x` (required, float)
          - `y` (required, float)    
      - `SeamPair` (optional, dict) denotes which shape and line are `sewn` (Clo op) to this shape/line
        - `shapeId` (required, unique string) form piece ID of adjoining pattern piece
        - `lineId` (required, unique string) form piece line ID for adjoining pattern piece sewn edge
  - `Mappings`
    - `WeaveStructure` (optional, string) 

## ArtworkArea
- `Name` (required, unique string)
  - `Index` (optional, int) Clo generated index
  - `ID` (required, unique string) Clo generated id.
  - `SVG` (required, full svg string) svg definition of corresponding pattern piece shape
  - `Color` (optional, hex color)
  - `LayerSystem` (required, string) string notation of warp (numeric)/weft (alpha) layer systems, use parenthesis to denote new layer grouping
   - `Mappings`
      - `FormPieces` (optional, list) form pieces (name) that get compressed into this artwork area
      - `WeaveStructureCompiled` (optional, string) name of compiled weave structure used in this area
    

## Weave Structure
- `Name` (required, unique string)
  - `DataArray` (required, array 1/0) array of single pattern repeat (1= warp lift, 0=no lift)
  - `ColorArray` (optional, array hex colors) array of weft colors for each pick in the corresponding repeat
   - `Mappings`
      - `Fiber` (optional, array of Fiber ref) array containing fiber id and ends distribution (start, end)

## Weave Structure Compiled
- `Name` (required, unique string)
  - `DataArray` (required, array 1/0) array of single pattern repeat (1= warp lift, 0=no lift)
  - `ColorArray` (optional, array hex colors) array of weft colors for each pick in the corresponding repeat
  - `WarpSequence` (optional, string)
    - `Mappings`
      - `ArtworkArea` (optional, string) artwork area name that weave structure maps into 
      - `WeaveStructures` (optional, list) list of individual weave structures 

## Yarn
- `Name` (required, unique string)
  - `FiberComposition` (optional, string)
  - `Color` (optional, hex color)
  - `Size` (optional)
